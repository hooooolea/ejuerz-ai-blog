上一篇说了[怎么把网站拖上 Cloudflare](/posts/deploy-site-cloudflare-pages-free/)——直接上传 HTML 文件，几十秒上线。

这篇说怎么让 AI 帮你生成这个 HTML 文件。

## 有一个坑

你直接让 AI「帮我做一个展示网站」，它十有八九会生成 React 或 Vue 代码。这种代码需要安装 Node.js、运行 `npm run build` 才能得到最终文件，没法直接上传。

解决方法很简单：在提示词里说清楚「用纯 HTML + CSS + JavaScript，单文件，不用任何框架」。

---

## 提示词模板

### 基础版——项目展示页

```
帮我用纯 HTML + CSS + JavaScript 做一个单页项目展示网站。
要求：
- 单个 HTML 文件，所有样式和脚本都写在文件里，不引用外部文件
- 不使用任何前端框架（不用 React、Vue、Svelte 等）
- 可以用 CDN 引入的库，比如 highlight.js
- 深色主题
- 响应式，手机端也能看

页面内容：
- 项目名称：[你的项目名]
- 一句话介绍：[项目介绍]
- 主要功能：[列出 3-5 个功能点]
- 技术栈：[用了什么技术]
- GitHub 链接：[你的仓库地址]
- 演示视频 / 截图：[如果有的话]
- 团队成员：[姓名列表]
```

### 进阶版——带交互的功能演示页

```
帮我用纯 HTML + CSS + JavaScript 做一个产品演示网站，单文件，不用框架。

页面结构：
1. 顶部导航（固定，点击跳转到各个 section）
2. Hero 区域（大标题 + 副标题 + 两个按钮）
3. 功能介绍（3 列卡片布局，每张卡片有图标、标题、说明）
4. 使用步骤（1-2-3 步骤说明）
5. 底部联系方式

设计要求：
- 白色主题，主色用 #2563eb（蓝色）
- 字体用系统默认字体，不引入外部字体
- 卡片有悬停效果
- 动画要轻，不要太花哨

填入内容：
产品名称：[名称]
核心卖点：[一句话]
三个主要功能：[功能1] [功能2] [功能3]
联系邮箱：[邮箱]
```

### 提示词展示页

```
帮我用纯 HTML + CSS + JavaScript 做一个提示词收藏网站，单文件，不用框架。

功能：
- 提示词以卡片形式展示，网格布局
- 每张卡片有标题、分类标签、简短描述、提示词原文（可滚动）
- 每张卡片右下角有「复制」按钮，点击复制提示词原文
- 顶部有分类筛选按钮，点击只显示该分类的卡片
- 支持深色/浅色模式跟随系统

提示词数据直接写在 JS 里，格式是一个数组，方便我后续自己改。

深色主题，卡片边框在悬停时高亮。
```

---

## 用法

把上面的模板贴到 ChatGPT 或 Claude 里，把方括号里的内容换成你自己的，发送。

AI 会生成一段完整的 HTML 代码。复制出来，保存成 `index.html`，然后按照[上一篇的方法一](/posts/deploy-site-cloudflare-pages-free/)直接拖到 Cloudflare Pages，几十秒上线。

## 如果 AI 生成的不满意

**样式不好看**：补一句「重新设计，参考 Linear 或 Vercel 官网的设计风格」

**内容不对**：直接说「第三个功能改成 xxx，颜色改成深色主题」

**代码有问题页面打开是空白**：把代码贴回去说「这段代码打开是空白页，帮我检查一下」

**想加功能**：继续在同一个对话里说「在页面底部加一个联系表单」，AI 会在原来的基础上修改。

---

## 关键词备忘

每次让 AI 做可以直接上传的网站，记住加这几个词：

> **纯 HTML + CSS + JavaScript，单文件，不用框架，不用构建工具**

有这几个词，AI 生成的代码拿来就能用。
